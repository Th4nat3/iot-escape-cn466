CN466 / ESP32-S2 / USB SERIAL / PING + ACK

CONNECT THE REAL BOARD.

หน้าทดสอบข้อมูลจาก ESP32-S2 ผ่าน USB Serial (115200 baud) และเป็นเกตเวย์ส่งคำสั่ง PING จากเกมเพื่อรอ ACK จากบอร์ดจริง ไม่อัปโหลด Firmware อัตโนมัติ และไม่อ้างว่ามีเซนเซอร์หากยังไม่ได้ต่อ ส่วน RGB ต้องใช้ Firmware เสริมและมีการยืนยันด้วยสายตา

NOT CONNECTED
เมื่อคลิก Connect ให้เลือกพอร์ต COM3 ของ ESP32-S2 แล้วกด Connect ในหน้าต่าง Chrome • Baud rate: 115200
ต้องปิด Serial Monitor ของ Arduino IDE, Python miniterm หรือโปรแกรมอื่นที่ใช้งาน COM3 ก่อน ไม่เช่นนั้น Chrome จะเปิดพอร์ตไม่ได้ • ให้เปิด COM3 ที่หน้านี้เพียงหน้าเดียว

PHONE HOTSPOT / WI-FI 2.4 GHz

ใช้ Firmware ใหม่ในโฟลเดอร์ firmware/IoT_Escape_ESP32S2_Hotspot ก่อนใช้งานส่วนนี้ · กรอกชื่อ Hotspot/รหัสผ่านในคอมพิวเตอร์เท่านั้น ไม่บันทึกในไฟล์เว็บ ไม่ส่งไปหน้าเกม และไม่ใช่การทดสอบเซนเซอร์

Wi-Fi: NOT REPORTEDHTTP: NOT TESTEDIP: —OPEN /status

Wi-Fi ต้องการ Firmware เวอร์ชัน Hotspot ใหม่ PING/ACK ผ่าน USB ไม่เท่ากับ Wi-Fi เชื่อมแล้ว ส่วน MQTT ยังไม่ได้ตั้งค่า Broker และยังไม่ใช้งานในชุดนี้

กรณีคอมพิวเตอร์ไม่ได้อยู่เครือข่ายเดียวกับ Hotspot: ปุ่ม TEST HTTP /status บนคอมอาจไม่ผ่านแม้บอร์ดเชื่อม Wi-Fi สำเร็จ ให้เปิดลิงก์ OPEN /status จาก Safari บน iPhone ที่ปล่อย Hotspot และเก็บภาพ JSON เป็นหลักฐาน HTTP แยกต่างหาก ผลบน Safari ไม่ได้เปลี่ยนสถานะทดสอบในเบราว์เซอร์คอมโดยอัตโนมัติ

CUCUMBER R — ONBOARD RGB LED (GPIO18) / OPTIONAL

เฉพาะผู้ที่อัปโหลด Firmware รุ่น IoT_Escape_ESP32S2_RGB_Bonus เท่านั้น • มี RGB LED บนบอร์ด Cucumber R ไม่ต้องใช้ LED หรือตัวต้านทานภายนอก • คำสั่งผ่าน USB Serial เท่านั้น ไม่เปิดพอร์ต HTTP สำหรับสั่ง LED

LIVE SERIAL LOG

รอการเชื่อมต่อกับพอร์ต Serial...

ข้อมูลจะปรากฏเมื่อ Firmware ส่งข้อความผ่าน USB เช่น Publish payload: {"temperature":null,...} เมื่อกด PING จากเกมจะมี TX COMMAND และเมื่อบอร์ดตอบจริงจะมี RX ACK (หากไม่มี ACK จะรายงาน Timeout)

สถานะ SERIAL CONNECTED หมายถึงเปิดพอร์ตได้ ส่วน LIVE SERIAL หมายถึงได้รับ JSON ผ่านพอร์ตแล้ว • ค่า null หมายถึงยังไม่มีข้อมูลจากเซนเซอร์ ไม่ใช่ศูนย์ • ข้อมูลและ data_origin เป็นสิ่งที่ Firmware รายงาน ไม่ใช่หลักฐานยืนยันความถูกต้องของเซนเซอร์
